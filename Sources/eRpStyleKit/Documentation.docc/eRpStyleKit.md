# ``eRpStyleKit``

Design system and UI components for the E-Rezept application.

## Overview

eRpStyleKit provides a comprehensive design system and reusable UI components for the E-Rezept application, ensuring visual consistency, accessibility, and user experience standards across all features.

This module contains:
- Design system components and tokens
- Reusable UI components and views
- Color schemes and typography definitions
- Icons, images, and visual assets
- Accessibility features and utilities
- Custom view modifiers and extensions

### Topics

#### Design System
- Color palette and theming
- Typography and font definitions
- Spacing and layout guidelines
- Visual design tokens

#### UI Components
- Buttons, inputs, and form elements
- Navigation and layout components
- Cards, lists, and data display
- Custom controls and interactions

#### Visual Assets
- App icons and imagery
- Custom graphics and illustrations
- Brand elements and logos
- Asset management and organization

#### Accessibility
- VoiceOver support
- Dynamic Type integration
- High contrast and accessibility colors
- Touch target optimization

#### Dependencies
This module depends on:
- ``eRpResources`` for assets and resources
