# ``AVS``

Contains a client for sending prescriptions to pharmacies directly, without the FD.

## Overview

AVS (Apothekenvertriebssystem) provides direct prescription delivery capabilities to pharmacies, bypassing the traditional Fachdienst (FD) route for specific use cases and enhanced workflow efficiency.

This module enables:

- Direct prescription transmission to pharmacies
- Alternative delivery workflows
- Pharmacy-specific communication protocols
- Streamlined prescription processing

### Topics

#### Direct Delivery

- Prescription transmission without FD intermediation (deprecated)
- Direct pharmacy communication
- Alternative workflow implementation
- Enhanced delivery efficiency

#### Communication Protocols

- Pharmacy-specific messaging
- Secure prescription transfer
- Delivery confirmation handling
- Error reporting and recovery

#### Dependencies

This module depends on:
- ``HTTPClientLive`` for network communication
