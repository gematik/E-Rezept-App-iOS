# ``IDPLive``

Live implementation of the IDP module for production environments.

## Overview

IDPLive provides the production-ready implementation of identity provider communication, offering real authentication services and live key management capabilities.

This module contains:

- Live authentication workflows

### Topics

#### Dependencies

This module depends on:

- ``HTTPClient`` for network communication
- ``IDP`` for protocol definitions
- ``TrustStore`` for certificate validation
- ``AsyncHelpers`` for async operations
