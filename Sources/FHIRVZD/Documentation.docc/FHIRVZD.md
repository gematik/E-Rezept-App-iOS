# ``FHIRVZD``

FHIR-based pharmacy directory service integration.

## Overview

FHIRVZD integrates with the FHIR-based pharmacy directory service (Verzeichnisdienst), providing comprehensive pharmacy lookup and information retrieval capabilities using standardized healthcare data formats.

This module provides:
- FHIR-compliant pharmacy directory access
- Structured pharmacy data retrieval
- Healthcare standard compliance
- Integration with pharmacy search services

### Topics

#### Directory Services
- FHIR-based pharmacy directory queries
- Structured pharmacy information
- Healthcare data standardization
- Service capability discovery

#### FHIR Integration
- FHIR resource handling for pharmacy data
- Healthcare interoperability standards
- Standardized data exchange protocols
- FHIR bundle processing

#### Dependencies
This module depends on:
- ``Pharmacy`` for pharmacy services
- ``HTTPClient`` and ``HTTPClientLive`` for network communication
- ``FHIRClient`` for FHIR operations
- ``eRpKit`` for domain models
- ``IDP`` for authentication
